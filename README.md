# ARCHATIA

Desktop aplikacija za prepoznavanje arhitektonskih stilova pomoću umjetne inteligencije.

## Opis projekta

ARCHATIA koristi lokalni CLIP model za analizu slike građevine te prepoznaje kojem arhitektonskom stilu pripada.

Aplikacija prikazuje:

* prepoznati stil
* definiciju arhitektonskog stila
* razinu sigurnosti predikcije
* alternativne moguće stilove
